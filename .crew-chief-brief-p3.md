# Brief — Piece 3: /modo recusa com mensagem clara (lado Python)

## Contexto
DECISÃO DE PRODUTO (resposta B): o modo jogo está desativado nesta frente. O lado Rust (`ciclo.rs`) já recusa o verbo `Jogo` (peça 2). Esta peça trata do endpoint `/modo` no lado Python (fora de `nucleo/vard/cerebro/`), que hoje entra em laço com o Rust.

## Objetivo
1. Localizar o handler do endpoint `/modo` no código Python do projeto (provavelmente em `nucleo/vard/modo.py`, `nucleo/vard/server.py`, ou similar — NÃO em `nucleo/vard/cerebro/`).
2. Fazer o handler retornar imediatamente um erro claro quando receber `{"modo": "jogo"}`:
   - HTTP status: 503 Service Unavailable (ou 400 Bad Request se 503 não for convencional neste servidor)
   - Body JSON: `{"ok": false, "erro": "modo jogo indisponível nesta versão"}`
3. Para `{"modo": "voltar"}`, retornar sucesso imediato sem tentar restaurar modelo/GPU:
   - Body JSON: `{"ok": true, "mensagem": "restauração pendente para próxima versão"}`
4. Quebrar qualquer laço de retry/chamada recursiva entre Rust e Python neste endpoint.
5. Se o endpoint `/modo` não existir no Python (apenas no Rust via ponte), documente isso na nota da tentativa e pule esta peça — a recusa já está coberta pelo Rust na peça 2.

## Arquivos permitidos
- Qualquer arquivo Python sob `nucleo/vard/` EXCETO `nucleo/vard/cerebro/**`
- Testes sob `nucleo/tests/`

NÃO toque em `src-tauri/`, `src/`, nem em `nucleo/vard/cerebro/`.

## Testes obrigatórios
Adicione testes em `nucleo/tests/test_modo.py` (ou arquivo equivalente):
- `test_modo_jogo_retorna_erro_claro`: POST `/modo` com `{"modo":"jogo"}` → status 503/400, body contém "indisponível".
- `test_modo_voltar_retorna_sucesso_imediato`: POST `/modo` com `{"modo":"voltar"}` → status 200, body contém `"ok": true`.
- `test_modo_desconhecido_retorna_erro`: POST `/modo` com `{"modo":"xyz"}` → status 400.

Rode `cd nucleo && python -m pytest tests/test_modo.py -v` e garanta que passa.
